# DIGI DIGI — Global Offensive (5v5 & Online)

Brauzerda va Telegram Mini App'da ishlaydigan CS2 uslubidagi 3D o'yin. Three.js va Express.js bilan qurilgan.

## O'ynash

- Web: [https://digi-digi.livops.app](https://digi-digi.livops.app)
- Telegram Mini App: `@BotFather` orqali ulangan holda

## Imkoniyatlar

- Three.js (3D grafika, 5v5 FPS, xaritalar, botlar)
- Telegram WebApp avto-profil sinxronizatsiyasi
- Do'st taklif qilish havolasi va o'zaro profillar
- 1 haftalik bloklash tizimi
- Express.js backend va ma'lumotlar bazasi
